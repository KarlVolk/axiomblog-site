Giving the Transformer Variable Compute
2026-05-28 · 10 min · #machine-learning #experiment-logbook

In this set of experiments I investigate different methods of incorporating variable compute allocation into the transformer architecture. Since test-time compute scaling relates the number of tokens produced to output quality, we already have a solution to variable compute: every token costs the same, but a request generates as many tokens as the task needs. Here I ask a different question: can a single token cost a variable amount? Starting with a small-scale character-based transformer, I wanted to see whether compute can be dynamically allocated to each token (character) in a way that improves upon the simple fully-connected and mixture-of-experts architectures.
